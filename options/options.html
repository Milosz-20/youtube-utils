YouTube Utils

YouTube Utils isn't allowed on YouTube and Songsterr yet, so nothing shows up there.

Features

Changes apply to open YouTube tabs right away.

User scripts

Tampermonkey-style scripts that run on YouTube. Paste a script with a ==UserScript== header; @name, @match and @run-at are read from it. Basic GM_* functions (getValue, setValue, deleteValue, addStyle) are provided.

User scripts need an extra permission in Firefox.

If the Firefox prompt closes by itself: open about:addons → YouTube Utils → Permissions tab and switch on the user scripts permission. This page updates automatically.

User scripts are allowed, but Firefox hasn't enabled the userScripts API for this page. Reload this page; if this stays, update Firefox (136 or newer needed).
